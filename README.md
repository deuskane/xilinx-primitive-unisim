# xilinx-primitive-unisim

**Xilinx `unisim` functional simulation library (release 11.1) packaged as a FuseSoC core for GHDL / non-ISE flows.**

## Introduction

This repository is an import of the Xilinx `unisim` VHDL library: the functional simulation models of the Xilinx device primitives (gates, LUTs, flip-flops, distributed and block RAMs, DSP, clocking, IO buffers, configuration cells...). The sources are third-party Xilinx code (`unisim_VCOMP.vhd`: "Copyright (c) 2011 Xilinx, Inc.", Release 11.1, generated by `gencomp.pl`); only the FuseSoC core file is Asylum-specific. Revision `11.1.1` of the core replaced the IEEE VITAL packages used by `unisim_VPKG.vhd` with the `IEEE_dummy` library of `asylum:utils:pkg`, so that the library compiles with GHDL in VHDL-2008 mode.

It is in the project to simulate Xilinx-primitive based code with an open-source simulator:

- `xilinx:processor:kcpsm:1.30` ([xilinx-processor-kcpsm3](../xilinx-processor-kcpsm3)) depends on it: the original PicoBlaze-3 netlist is written with `unisim` primitives (`LUT*`, `FD*`, `MUXCY`, `XORCY`, `RAM16X1D`, `RAM32X1S`, `RAM64X1S`...).
- `asylum:processor:OpenBlaze8` depends on it in its `files_sim` fileset, together with kcpsm, because its testbench runs `kcpsm3` as a lock-step reference model.
- The `xilinx` ROM model of the `asylum:utils:generators` ROM generators (`generators/gen_rom/ROM/xilinx/ROM_form.vhd`, `RAMB16_S18`) also uses `library unisim`; no core of the project currently selects this model.

The fileset is declared as `"!tool_ise?(files_hdl)"`: it is skipped when the FuseSoC tool is Xilinx ISE, which ships its own precompiled `unisim` library.

### Key Features

- VHDL library `unisim` (`logical_name: unisim`), usable with `library unisim; use unisim.vcomponents.all;`
- Package `VCOMPONENTS` ([hdl/unisim_VCOMP.vhd](hdl/unisim_VCOMP.vhd)): 1167 component declarations
- Package `VPKG` ([hdl/unisim_VPKG.vhd](hdl/unisim_VPKG.vhd)): shared types and helper functions of the models (multi-dimensional `std_logic_vector*` types, memory collision types, ...)
- 1130 primitive models in [hdl/primitive/](hdl/primitive/), listed in the core in the Xilinx `vhdl_analyze_order`
- `hdl/secureip/` (GT transceivers, PCIe, EMAC/TEMAC, PPC405/PPC440, MCB, PHASER, ISERDESE2/OSERDESE2...) is present but **not** part of the fileset
- Simulation models only: not intended for synthesis (synthesis tools infer / provide these primitives themselves)

## Block Diagram

- `unisim_VPKG.vhd` and `unisim_VCOMP.vhd` are compiled first; `VPKG` uses `IEEE_dummy.VITAL_Timing` / `VITAL_Primitives` from `asylum:utils:pkg`.
- The primitive models are grouped by function: logic / LUT / carry, flip-flops and latches, distributed RAM / SRL, block RAM / FIFO, DSP / multipliers, clocking, IO buffers / SERDES, configuration / debug and miscellaneous cells.
- There is no top-level entity and no port: users instantiate individual primitives.

## Top-Level

This IP is a primitive library: there is no top-level entity. The `default` target only lists the `files_hdl` fileset (no `toplevel`).

### Usage Example

```vhdl
library unisim;
use     unisim.vcomponents.all;

  ins_fdre : FDRE
    generic map
    ( INIT => '0'
    )
    port map
    ( Q  => q
     ,C  => clk
     ,CE => ce
     ,R  => rst
     ,D  => d
    );
```

## Directory Structure

```
xilinx-primitive-unisim/
├── unisim.core             # FuseSoC core (xilinx:primitive:unisim)
├── README.md
└── hdl/
    ├── unisim_VPKG.vhd     # Package VPKG
    ├── unisim_VCOMP.vhd    # Package VCOMPONENTS
    ├── primitive/          # 1130 primitive models + vhdl_analyze_order
    └── secureip/           # 39 secureip models + vhdl_analyze_order (not in the core)
```

There is no Makefile, `mk/` folder, testbench or CI workflow in this repository. The library is consumed through FuseSoC by adding `>=xilinx:primitive:unisim:11.1` to the `depend` list of a fileset (as done by `xilinx:processor:kcpsm` and `asylum:processor:OpenBlaze8`); FuseSoC then compiles the files into the `unisim` library before the depending cores.
